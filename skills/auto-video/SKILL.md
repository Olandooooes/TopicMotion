# TopicMotion · 自动制作动效视频

TopicMotion 是产品名称；保持 name=auto-video 和 $auto-video 调用以兼容已有安装。自动制作与解释型动效是核心，卡通只是形式选项之一。

用户给话题后，使用当前对话模型完成内容与分镜，使用本 Skill 的本地程序完成配音和渲染；不要求另配模型 API，不启动第二个聊天模型或子代理。用户不需要手写脚本或操作时间线。Skill 是在 Codex 中运行的制作流程，不是离开 Codex 后独立生成任意话题的网页服务。

## 从请求到成片

- 从用户指令提取话题、风格、时长。未给的可默认：中文、cartoon、30 秒、横屏 1280×720。已有明确偏好时沿用，不为例行制作反复提问。
- 需要核验事实时先检索权威来源。把资料改写成适合口播的内容，避免无根据统计、虚构引用和把解释性图形称为实测数据。不要把内置 RAG 示例当成任意话题的固定脚本。
- 阅读 [任务格式与风格](references/job-format.md)。按话题编写原创场景 JSON，控制总字数约每秒 2.5–3.2 个汉字，为转场和停顿留空间。将生成的任务保存到用户工作目录，输出使用新目录。
- 执行本 Skill 的 `scripts/render.mjs --job /绝对路径/job.json --out /绝对路径/输出目录`。以实际 Skill 文件位置定位脚本，不假定仓库路径。程序首次缺少依赖时用 npm ci 安装已锁定依赖，不需要用户的模型密钥。
- 根据内容选择画面：发酵使用 fermentation（面团内部气泡与轮廓膨胀），HTTP缓存命中/回源使用 cache（双分支请求响应）；其他内容使用 hook/index/retrieve/context/answer/limits 六种连续动效；按内容选择拆分、排序、合并、卡片变形及总结，不把示意条形当作实测统计。填写 detail/result/sourceLabel/note，避免沿用示例话题。
- 程序自动复用有效句级缓存或合成新配音，测量实际长度，对齐字幕和场景，生成动画并导出 MP4、封面、脚本、SRT、时间线和报告。若提示文案过长，压缩该场景文案后在新输出目录重试；不要截断口播假装完成。
- 检查实际视频：至少开头、中间、片尾的画面，时长、中文字体、口播是否被切断和字幕遮挡。出错时修复并验证，不能把仅完成文案或预览页面当作成片。
- 返回可播放成片、脚本和输出位置，说明本次风格、实际时长和重要限制。默认只本地制作；用户要发布时再按其授权处理。

## 当前运行边界

默认配音为在线 Edge 神经声音 `zh-CN-XiaoxiaoNeural`，语速 -12%，句间停顿 0.32 秒；无需 API 密钥，但会向该服务发送口播文本。首次用 Python 3 创建虚拟环境并安装 edge-tts 7.3.1。网络或服务失败会报错，不静默回退。可显式设置 voice.provider=system 使用 macOS Tingting。当前完整流程在 macOS 验证，需要 Node 22.13+、Python 3、Chrome/Remotion 浏览器；不承诺其他平台一键运行。

三个内置画面风格是程序化 motion graphics，不是生成式实拍或逐帧角色动画。不把这些尚未实现的能力当作可选项展示。图片或真实镜头若后续加入，需有实际素材来源和相应使用权限。

代码与自制 SVG 适用项目 MIT；Remotion 依其自身许可。合成语音输出只作用户本地试听，不自动纳入开源许可或对外发布。不要提交输出目录、临时配音、.voice-cache 或用户素材。缓存含口播原文和音频，保持本地私密。失败重试时使用新输出目录，保留同一缓存路径；仅复用配音，视频会重新渲染，不宣称逐帧续跑。
