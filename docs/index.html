知识，怎样变成答案？

从一叠资料，到一条有出处的回答。
点击播放，用五秒看知识流动起来。

01 / RETRIEVE

先查资料

从知识库中寻找与问题相关的片段，筛掉无关内容和过期版本。

02 / AUGMENT

整理证据

把可用的资料作为上下文提供给模型，同时保留来源信息。

03 / GENERATE

带着证据回答

生成回答并展示引用；引用方便核查，并不保证答案一定正确。

这是动画演示，排序条不是统计图；制度与“30 天”均为虚构教学案例。
默认无声，你可以在源码项目中替换为自己的配音。
