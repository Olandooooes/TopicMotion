换成你的声音

选择一段录音，再点击“播放动画”。声音会跟随动画暂停、拖动和重播。文件仅在本浏览器中读取，不会上传。

尚未选择录音，当前播放无声示例。

建议使用约 5 秒的 MP3 或 WAV：0.15 秒开始“先查资料”，2.2 秒开始“再带着证据回答”。较长录音只播放到动画结束，较短录音结束后保持无声；字幕不会自动更改。刷新或关闭页面后需重新选择录音。此处仅同步试听，下载按钮仍提供原无声 MP4。
01 / RETRIEVE

先查资料

从知识库中寻找与问题相关的片段，筛掉无关内容和过期版本。

02 / AUGMENT

整理证据

把可用的资料作为上下文提供给模型，同时保留来源信息。

03 / GENERATE

带着证据回答

生成回答并展示引用；引用方便核查，并不保证答案一定正确。
